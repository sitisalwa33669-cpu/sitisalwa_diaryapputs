# Taman Ceritaku 🌿 - Aplikasi Buku Harian Digital

Aplikasi _mobile_ berbasis React Native untuk mencatat jurnal dan cerita sehari-hari dengan tema tanaman (botanikal) yang menenangkan. Proyek ini dibangun untuk memenuhi Ujian Tengah Semester (UTS) mata kuliah **Mobile Programming Native**.

## 🎯 Fitur dan Pemenuhan Syarat UTS

Aplikasi ini dirancang sesuai dengan ketentuan soal ujian:

- **Minimal 4 Komponen:** Terdiri dari `Header`, `EntryCard`, `CustomButton`, dan `EmptyState`.
- **Penggunaan State & Props:** Aliran data diatur menggunakan _Props_ (mengirim data catatan ke kartu) dan _State_ (menyimpan daftar memori yang ditambahkan).
- **Navigasi Halaman:** Menggunakan `@react-navigation/native-stack` untuk perpindahan mulus dari halaman _Home_ ke halaman _Tambah Catatan_.
- **Penerapan Hooks:** Menggunakan `useState` dan `useEffect` untuk memperbarui daftar catatan secara dinamis.
- **Tema Bermanfaat:** Tema buku harian untuk mendukung kebiasaan menulis jurnal (_journaling_) demi kesehatan mental dan refleksi diri.

## 🛠️ Teknologi yang Digunakan

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [React Navigation](https://reactnavigation.org/)
- Expo Vector Icons (Ionicons)
